## 三、已定结论与栗子偏好（不要重新讨论）

**体系（栗子拍板，已实现）**
- 四区仍是 `AI / 资源 / 工具 / 创意`，**不推翻**。
- 判定 = 三分支二分链，**第一个答「是」的就是结果，三问全否 = 工具**：
  1. 问 1 它是「作品」吗（玩/看/听/自己动手创作）→ **创意**
  2. 问 2 它是「读物」吗（不安装不运行、读/下载就拿全部价值）→ **资源**
  3. 问 3 它是「智能本体」吗（拿掉 AI/模型什么都不剩）→ **AI**
- 判例（写进 prompt/脚本/文档三处同源）：skill 包 → **AI**（栗子点名的错分在此闭死）；AI 教程/清单 → **资源**；
  AI 绘画工作台 → **创意**；Agent 框架/推理引擎 → **AI**；游戏引擎/开发框架 → **工具**；带 AI 摘要的自托管笔记 → **工具**。
- 互斥性由构造保证（工具区=三问全否），不靠抽查。

**乐趣（六维，推测执行 + 已标注假设）**
- 六维：意外感 `surprise` / 可玩性 `play` / 奇观 `wow` / 荒诞 `absurd` / 表达欲 `voice` / 稀缺性 `rarity`；
  合成 `fun = max(六维) + 0.1×(命中维数−1)`，封顶 1。
- 三条反污染纪律：**题材不加分**（AI/热话题本身不加）、**「是个游戏」不加分**、正经生产力工具六维全 0。
- 判定输入 = repo/语言/星数/建仓时间 + desc(≤200) + topics(≤8) + summaryCn(≤120) + reasonCn(≤220) + **detailCn 全文(≤900)**。

**频道（拍板）**：容量无限；页面显示**真实池子张数**；配额是**前缀约束**不是成员筛选（不丢卡）。

**工作偏好（反复出现的）**
- 未说明的细节一律**推测执行**，做完在结果旁标注关键假设，不零散提问。
- 一切结论**用实测数字**，标证明等级（已实测/推断/未验）。
- 不合格卡不上站；`data/feed.json` 改动**必须 push**（push 即上线）。
- 每个「完成」必须附**线上反查证据**。
- 密钥零回显，只读 `D:/AI/KEY/`。

| agnes | 探针 ✓，但「多张 × detail 900 字」真实批次**悬住不返回** | 默认不启用（脚本 `--agnes` 关闭） |

| 并发跑两个回填进程 | 同写 feed+state → 凭证从 394 **倒退回** 355 | 单写入者：`src/feed/file-lock.ts` + 每次只起一个进程 |
| `ONLY=$(cat f) cmd --only="$ONLY"` | 同一行 env 赋值不参与展开 → `--only` 拿到空值 → 误跑全库 | 先 `A=$(cat f)` 再单独一行用 `"$A"` |
