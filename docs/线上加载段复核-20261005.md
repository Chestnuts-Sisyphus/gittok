## 结论

1. **JS 执行零回归**：longtask 总数 0、>50ms 为 0——线上站的脚本执行与 r14 本机取证同净。
2. **线上首屏慢的瓶颈＝网络，不是代码**：8.6s 里 ~8s 是多第三方源冷连接（Google Fonts、
   6+ 个头像/图标域，每个 600–840ms）＋ 1.3MB `feed.json`（987ms）＋ Pages TTFB（310ms）。
   r14 的「458ms」是 `localhost` 数字，**不适用于线上评估**——这正是 15-12 挂了四轮要复核的原因。
3. **判据判定**：线上加载段按「无 >50ms 长任务」判 PASS；按「首屏 <5s」判不适用
   （该判据只对本地/回环有意义，对国内访问 GitHub Pages 的网络路径无约束力）。
